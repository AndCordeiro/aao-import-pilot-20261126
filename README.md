# aao-import-pilot

Disposable repository for the imported-delivery pilot of the Alcateia AI Orchestrator (ADR-025). It holds no secret
and no personal data, has no dependencies and can be deleted after the pilot.

| Action  | Command                          |
| ------- | -------------------------------- |
| Install | `pnpm install --frozen-lockfile` |
| Verify  | `pnpm run verify`                |
| Test    | `pnpm test`                      |
